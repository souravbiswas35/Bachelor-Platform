# Bachelor-Platform
A complete all-in-one platform designed to make bachelor life easier with rentals, meal tracking, marketplaces, and community connections.

---

## 📌 Overview
Bachelor-Platform is a comprehensive web-based solution created to simplify and organize the daily lifestyle of bachelors. From finding a place to stay to managing meals, expenses, and community interactions, everything is integrated into one seamless platform.

---

## 🎯 Purpose
Bachelors often face challenges in managing their living space, food expenses, social needs, and overall organization. This platform solves these issues by providing an intuitive, easy-to-use system that centralizes essential services.

---

## 🚀 Key Features

### 🏠 Room & Seat Rentals
- Search and book available rooms or seats  
- View pricing, amenities, and availability  
- Direct communication with owners  

### 🍽️ Meal Tracking System
- Track daily meals  
- Calculate monthly meal costs  
- Easily manage shared meal expenses  

### 🛍️ Marketplace
- Buy and sell products within the bachelor community  
- Post items with images and descriptions  
- Fast and secure communication between buyers and sellers  

### 👥 Area-Based Community Groups
- Join local groups based on your area  
- Share updates, ask questions, and stay connected  
- Build a supportive social environment  

---

## 🔧 Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP (MySQL)  
- **Rich Text Editor:** TinyMCE  
- **Database:** MySQL  

---

## 🎨 Design Philosophy
- Clean and modern UI  
- Simple navigation  
- Mobile-responsive layout  
- Built for convenience and community  

---

## 👤 Target Users
- Students living in bachelor housing  
- Young professionals  
- Anyone sharing rooms or living independently  

---

## 📬 Getting Started

### Clone the repository:
```bash
git clone https://github.com/souravbiswas35/Bachelor-Platform.git
```

### Configure the backend:
- Import the provided SQL file into MySQL  
- Update database credentials in `config.php`  
- Run the project on any PHP-supported environment (XAMPP, WAMP, LAMP)
